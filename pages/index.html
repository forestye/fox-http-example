卷之三

梗概。

本仓凑齐 fox 一系的四件组件，做成一份端到端示例。各司其职：

fox-http
运行时 HTTP 服务器；零拷贝 writev + 协程 IO。
fox-route
routes.crdl → C++ Router 代码生成；编译期解析路径参数与返回类型。
fox-page
HTML 模板 → 零拷贝 writev 渲染函数；本页即由它产出。
fox-mysql
MySQL 连接池 + 简单 Repo 模式。
