Nº 03 / Authenticate

Sign in, politely.

POSTs to /login as x-www-form-urlencoded. The placeholder accepts any username so long as the password is the literal word password.

The handler reads username and password from the form, validates lazily, and on success sets a session_token cookie before returning { "ok": true } as JSON.

This is example code — do not copy the auth path into anything that matters.
