Nº 02 / 能力一览

四条路由，
四种风格。

下面每个端点都用 fox-http 的不同特性实现，点开任意一条即可看到运行时表现。

01 — HTML

服务端渲染的用户名册

用 cpp-for 遍历 user 表的每一行，编译期烧进二进制，请求时直接返回缓存好的 HTML。

GET /users
02 — JSON

类型化的 JSON 处理函数

handler 直接返回 Json::Value 即可，序列化、Content-Type、Content-Length 都自动办好。

GET /userinfo/{id}
03 — 路径

类型化的路径参数

{int:id} 与 {string:dir} 直接落进 handler 签名，不需要一行胶水代码。

GET /test/{dir}/string/{id}
04 — 原始

零拷贝 writev

想抠分配开销时，手写 iovec，body 直接从 string_view 推到 socket。

GET /hello
Nº 03 / 登录

请登录，
礼貌地。

用 x-www-form-urlencoded 编码 POST 到 /login。占位逻辑：用户名任意，但密码必须是字面量 password。

handler 从表单里取 username 和 password，做一遍最朴素的校验。成功时塞一个 session_token cookie，再返回 JSON { "ok": true }。

仅作示例，不要把这套鉴权抄进任何认真的项目里。
